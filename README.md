# Engineering Portfolio — Ankit Panicker

Architecture and systems write-ups for a portfolio of production-grade AI infrastructure built solo over ~12 months. Shared engineering philosophy across every project: **local-first, cost-constrained, multi-tenant, reliability-focused, built on consumer hardware.**

The ecosystem centers on one core product — **APEX Voice AI** — with surrounding systems that feed into or extend it: a marketing frontend (AIM), an offline hospital management system (APEX-HMS), a local video generation tool (Shortz), a fully offline voice agent (Asha), and earlier-generation desktop agents.
